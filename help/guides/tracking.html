# Tracking

Tracking connects manga in Tachimanga to external services so that your reading progress and other details stay up to date.

# Supported trackers

Tachimanga supports the following tracking services:

  • MyAnimeList (opens new window)
  • AniList (opens new window)
  • Bangumi (opens new window)
  • MangaUpdates (opens new window)
  • MangaBaka (opens new window)

Bangumi, MangaUpdates, and MangaBaka are currently in beta (opens new window).

With regular Tracking, a manga can be linked to one or more of these services. The available status, score, and reading-date options vary by service.

Tachimanga also provides Enhanced Trackers for these server-based extensions:

  • Komga
  • Kavita
  • Suwayomi

Enhanced Tracking for Komga, Kavita, and Suwayomi is currently in beta (opens new window).

# Set up Regular Tracking

# Sign in to a tracking service

  1. Go to More -> Tracking.
  2. Tap a service under Tracking services.
  3. Complete the login process.

Tracker login credentials are stored on the device and are not transferred by Tachimanga Sync. You may need to sign in again on another device.

# Add Tracking to one manga

  1. Open the manga.
  2. Tap Tracking.
  3. Tap Add tracking for the service you want to use.
  4. Select the correct search result.

If the correct result is not shown, edit the search text and search again.

# Add Tracking to multiple manga

  1. Open Library and select the manga you want to track.
  2. Tap the three-dot menu in the bottom-right corner.
  3. Select Tracking.
  4. Select a logged-in tracking service.
  5. Review the automatic matches. You can correct a match or exclude a manga before continuing.
  6. Confirm the results to add the tracking entries.

Manga already linked to the selected service are skipped. Bulk Tracking is only needed for regular tracking services; Enhanced Trackers match compatible manga automatically.

# What is Enhanced Tracking?

Enhanced Tracking is intended specifically for manga that you read through a Komga, Kavita, or Suwayomi extension. It reuses the server connection already configured in that extension, automatically matches compatible manga, and merges reading progress between Tachimanga and the server.

Enhanced Tracking does not apply to manga from other extensions. If you do not use Komga, Kavita, or Suwayomi, you can ignore it.

# Regular vs. Enhanced Tracking

Regular Tracking Enhanced Tracking
Works with MyAnimeList, AniList, Bangumi, MangaUpdates, and MangaBaka Manga from a Komga, Kavita, or Suwayomi extension
Manga matching Search for and link each manga manually, or use Bulk Tracking Automatically matches manga from the corresponding extension
Progress from Tachimanga Uploads to the tracking service automatically Uploads to the server automatically
Progress to Tachimanga Prompts you to apply remote chapter progress Merges remote and local chapter progress automatically

# Set up Enhanced Tracking

  1. Install and configure the corresponding Komga, Kavita, or Suwayomi extension.
  2. Go to More -> Tracking.
  3. Enable the corresponding service under Enhanced Tracking.
  4. To match compatible manga already in your library, confirm Match existing library manga?.

Matching existing manga runs in the background and its progress is shown on the Tracking screen. After the Enhanced Tracker is enabled, compatible manga are also matched automatically when they are added to your library.

If an Enhanced Tracker is unavailable, install and configure its corresponding extension first. Only manga from that extension can be matched by the tracker.

# How progress is updated

  • Reaching the last page of a chapter or manually marking a chapter as read uploads the new progress.
  • Starting a manga updates its reading status and start date when supported by the service.
  • Reaching the final known chapter updates its completion status and finish date when supported.
  • Changes made in the Tracking panel, including status, chapter, score, and reading dates, are sent immediately.
  • Automatic progress updates only move forward. They do not mark chapters as unread or roll progress back.

# Refresh progress from a regular tracking service

Tachimanga checks every linked tracker when you open a manga's Tracking panel. You can also open a tracker's three-dot menu and tap Refresh.

  • If local progress is ahead, Tachimanga uploads it to the tracking service.
  • If remote progress is ahead, tap Apply when prompted to mark the corresponding available local chapters as read.
  • Applying remote progress does not mark later chapters as unread.

# Refresh progress from an Enhanced Tracker

Enhanced Trackers automatically merge progress when they are matched or refreshed:

  • Chapters completed on the remote server are marked as read in Tachimanga.
  • Continuous reading progress that is further ahead in Tachimanga is uploaded to the remote server.

# Filter the Library by tracker

  1. Open Library and tap the filter button.
  2. Find the Tracked section.
  3. Tap a tracking service to include or exclude manga linked to it.

Only services that are currently logged in or enabled are listed in this section.

# General questions

# How is Tracking different from Sync?

Tracking manages individual manga entries and reading progress on external services. Sync keeps your Tachimanga library, categories, reading data, and other supported data synchronized between your devices.

Tracker records are included in Sync, but tracker login credentials are not.

# What can I do from a manga's Tracking panel?

For each linked entry, you can:

  • Refresh its remote data.
  • Open the entry on the tracking service.
  • Change supported status, chapter, score, and reading-date fields.
  • Remove the tracking entry from the manga.

# What should I do if a tracker login expires?

Go to More -> Tracking, log out of the affected service, and then log in again to refresh its authentication token.

# Can't find a manga on MyAnimeList?

Find the manga on MyAnimeList and copy the numeric ID from its URL. Then search in Tachimanga using id:<id>, for example id:13.

You can also search your MyAnimeList profile list using my:<manga name>.
