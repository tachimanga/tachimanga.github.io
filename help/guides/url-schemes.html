# URL Scheme Shortcuts

Use tachimanga://go?url=… to open a page directly in Tachimanga from a shortcut, launcher, or link. Tachimanga must be installed on the device opening the URL.

# Common shortcuts

Copy a URL below into your shortcut or launcher.

Destination URL
Global Search tachimanga://go?url=/global-search
Library tachimanga://go?url=/library
Updates tachimanga://go?url=/updates
Browse tachimanga://go?url=/browse
History tachimanga://go?url=/history
Downloads tachimanga://go?url=/downloads
Downloaded manga tachimanga://go?url=/downloaded
Reading time statistics tachimanga://go?url=/stats/time

# Search for a title

Global Search accepts a query parameter. Keep /global-search?query= as written and append the keyword:

tachimanga://go?url=/global-search?query=Naruto

For a title containing spaces, such as One Piece, replace each space with %20:

tachimanga://go?url=/global-search?query=One%20Piece

The keyword is passed to Global Search. Results follow your current search preferences and available sources.

# Advanced shortcuts

These shortcuts open specific content. Replace the values in braces with the corresponding internal IDs from your current Tachimanga data; do not include the braces in the final URL.

# Open a manga

tachimanga://go?url=/manga/{mangaId}

For example, if the manga's internal ID is 123:

tachimanga://go?url=/manga/123

# Read a chapter

tachimanga://go?url=/reader/{mangaId}/{chapterIndex}

chapterIndex is the chapter's internal index, not its displayed chapter number or chapter ID. Use the index belonging to that manga.

For example, for manga ID 123 and chapter index 5:

tachimanga://go?url=/reader/123/5

# Browse a source

Destination URL template
Popular manga tachimanga://go?url=/source/{sourceId}/popular
Latest manga tachimanga://go?url=/source/{sourceId}/latest
Source filter page tachimanga://go?url=/source/{sourceId}/filter

Use the source's internal sourceId. The source must be installed and available on the device. Available lists and filters depend on the source. These URLs do not accept a search keyword or filter values.

# View an extension

tachimanga://go?url=/extension/{extensionId}

Use the extension's internal extensionId, not a source ID or package name.

# About internal IDs

Manga and extension IDs refer to records in the current device's Tachimanga data. A URL containing an ID may not work on another device or after data is replaced. Source IDs must also match an available source. The numeric examples above illustrate the format; replace them with your own values.

# Build URLs with parameters

You do not need to encode the fixed prefix tachimanga://go?url=/global-search?query=. Plain keywords such as Naruto can be appended directly, and spaces can be written as %20.

Keywords containing &, +, #, or % need additional encoding because the link is parsed twice: first to read url, then to read query. For example, to search for A&B, use:

tachimanga://go?url=/global-search?query=A%2526B

For generated links that need to handle any keyword, encode only the keyword twice. For example, in JavaScript:

const keyword = 'A&B';
const url = 'tachimanga://go?url=/global-search?query='
  + encodeURIComponent(encodeURIComponent(keyword));

This produces the A&B URL shown above. For One Piece, this method produces One%2520Piece, which also works; the simpler One%20Piece form above is sufficient for a space. The fixed path stays readable in both cases.
