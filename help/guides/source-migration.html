# Source migration

Migration transfers selected data from a manga entry to another entry. Use it to switch sources, choose another version, or reconnect an old Library entry after a website redesign.

WARNING

Create a backup before migrating: Settings → Backup & Restore → Create Backup. Install and enable the target sources, and check that they can search and load chapters. Always review the target title, language, and chapters before confirming.

DANGER

Downloaded chapters do not transfer between sources. When replacing the original Library entries, review Delete original downloads before confirming. Keeping the original entries also keeps their downloads. Library backups do not include downloaded chapters or local source files.

# How do I migrate one manga?

  1. Open the manga’s more menu → Migrate.
  2. Search for and select the target manga.
  3. Choose Chapters, Categories, and Tracking as needed, and set whether to keep the original entry and its downloads.
  4. Tap Start migration.

# How do I migrate manga from one source?

  1. Open Browse → Migrate → original source. This lists your Library manga from that source.
  2. Open the more menu → Migrate all to migrate all entries shown, or long-press to select specific manga → Migrate.
  3. Follow the bulk migration steps to choose target sources, review matches, and confirm.

To migrate just one manga, tap its row and follow the single-manga steps.

# How do I migrate multiple manga?

  1. Long-press a manga in Library, select the entries to migrate, and choose Migrate. You can select manga from different sources. To filter by source first, use Sources in the Library filters.
  2. Select and order the target sources. In Migration Settings, choose the data to transfer, original-entry and download options, and matching strategy.
  3. Review the matches. To correct one, use Search manually → choose a target → Select this entry. Use Don’t migrate to skip an entry.
  4. Tap Continue, review the batch, enable Create a backup before migrating, and tap Start migration.

Matching does not change your Library. Only matched entries you keep in the batch are migrated. After completion, check your Library and reading progress.

# Which matching strategy should I choose?

Choose a few reliable sources and put your preferred ones first.

  • Use first source with alternative: Searches in order and stops at the first suitable match.
  • Use source with the most chapters (slower), Premium: Compares matches across all selected sources and chooses the one with the most chapters.

Automatic matches may be a different edition or language. Review them before migrating.

# What if Library manga stop loading after a source update?

Major website changes can give manga new addresses. After the source is updated, existing Library entries may still point to the old pages.

If searching that source finds the manga and its chapters load normally, try migrating the old entry to the newly found one on the same source (A → A).

For multiple affected manga, follow the source migration steps and select that same source as the target. Review the matches before confirming.

# What if no match is found or migration fails?

Try Search manually with a shorter title or an alternative name. If an expected source is missing, check Only search pinned sources.

If matching is unfinished, Wait lets the remaining searches finish. Migrate now stops them and proceeds with the matches already found.

Some entries may succeed even if others fail. Check the completion summary and Library. Before retrying, verify that the remaining entries’ target sources can load their manga and chapters, then retry only entries that still need migration.
